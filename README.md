# VN Bakes

Shop front for [VN Bakes](https://www.instagram.com/vn__bakes__/) — home bakers in Red Hills / Korattur.

- Custom cakes, brownies, chocolates, flower & treat bouquets
- Enquiries on the website → WhatsApp continuation
- Firestore business id: `vn-bakes` (Firebase project may stay `cakes-by-kee`)
- Visify desk: https://visify-apps.github.io/visify-desk/

```bash
npm install
npm run dev
npm run deploy:pages
```
